# Руководство пользователя «Автопарк»

## Вход

1. Запустите `FleetManager.exe`.
2. Введите логин и пароль (демо-доступ показан на экране входа).
3. Нажмите **Войти в систему**.
4. Если база данных недоступна, под кнопкой появится сообщение об ошибке —
   проверьте `appsettings.json`.

Сменить свой пароль: нажмите на **имя пользователя** в правом верхнем углу →
**Сменить пароль**. Выйти из системы: там же → **Выйти из системы**.

## Дашборд

- KPI: автомобили на линии, в ремонте, ожидают ТО, списаны, пробег за месяц;
- график расходов по месяцам (топливо и ТО);
- блок «Требует внимания» — ближайшие и просроченные ТО;
- «Последние поездки» — последние записи пробега
  (водитель видит только свои).

Кнопка **Обновить** перезагружает данные.

## Транспорт (администратор, диспетчер)

- поиск по номеру/марке/модели, фильтр по статусу;
- **Новый автомобиль** — марка, модель, госномер, год, статус, пробег;
- выберите строку и нажмите **Изменить**;
- экспорт **Excel** / **PDF**.

## Водители

- **Новый водитель** — выберите учётную запись (свободные пользователи роли
  «Водитель»), укажите удостоверение, категорию, телефон, дату найма;
- удостоверение обязательно, телефон — минимум 10 цифр;
- отключение водителя не удаляет историю.

## Маршруты

- **Новый маршрут** — начальный и конечный пункты, даты, расстояние,
  водитель, автомобиль, статус;
- обязательны обе точки маршрута;
- водитель видит только свои маршруты.

## Пробег

- **Новая запись** / **Внести пробег** — автомобиль, водитель, дата,
  одометр на начало и конец, примечание;
- пробег рассчитывается автоматически (`конец − начало`);
- проверяется, что конечный одометр не меньше начального;
- водитель вносит пробег только по своим поездкам;
- в таблице отображаются дата, автомобиль, водитель, одометр, пробег,
  примечание и кто внёс запись.

## ТО и ремонт

- верхняя таблица — сроки по каждому автомобилю и виду ТО
  (просрочено / наступило / приближается);
- **Выполнить ТО** — дата, пробег, стоимость, исполнитель, примечания,
  вложение (фото/акт). После сохранения план обновляется;
- **Планы ТО** — индивидуальные интервалы: вид ТО, интервал в км,
  последний пробег/дата, следующая дата, активность;
- **Скрыть уведомления** — подтвердить просмотр;
- нижняя таблица — журнал выполненных работ.

Для водителя раздел называется «Уведомления ТО» и показывает только просмотр.

## Топливо (администратор, диспетчер)

- **Новая заправка** — автомобиль, водитель, дата, литры, цена, одометр;
- сумма считается автоматически;
- вкладки/фильтры показывают план и факт расхода, отклонения;
- экспорт Excel/PDF.

## Штрафы и ДТП

- **Новый штраф / ДТП** — тип, дата, сумма, описание, статус оплаты;
- фильтры по типу и статусу, экспорт.

## Пользователи (только администратор)

- **Новый пользователь** — ФИО, логин, роль, пароль (≥8 символов), телефон;
- **Изменить** — данные и роль;
- **Сбросить пароль** — задать новый пароль пользователю;
- **Отключить/Включить** — блокировка входа без удаления истории;
- логин должен быть уникальным.

## Аудит (только администратор)

- журнал действий: входы, неудачные попытки, создание/изменение записей,
  сброс паролей;
- поиск по пользователю, действию, таблице; фильтр по дате;
- экспорт Excel/PDF.

## Уведомления ТО

- колокольчик в правом верхнем углу показывает количество активных
  уведомлений;
- нажмите на колокольчик, чтобы открыть список и перейти к разделу ТО;
- при новых критичных уведомлениях появляется всплывающее сообщение
  и звуковой сигнал (для администратора и диспетчера);
- пороги: 500 км — предупреждение, 0 км — наступило,
  −1000 км — просрочено (настраиваются в `appsettings.json`).

## Темы и экспорт

- переключение светлой/тёмной темы — кнопка в нижней части сайдбара;
  выбор сохраняется между запусками;
- экспорт доступен в разделах, где есть кнопки **Excel** и **PDF**;
- файл сохраняется в выбранную папку (имя предлагается автоматически).

## Горячие советы

- глобальный поиск в верхней панели: введите запрос и нажмите **Enter**;
- двойной клик по строке таблицы открывает редактирование (там, где доступно);
- «зебра», сортировка по клику на заголовок, пагинатор внизу таблицы;
- при ошибке подробности всегда есть в
  `%APPDATA%\FleetManager\logs\app-YYYYMMDD.log`.
